# The Profile Ledger

A responsive static publication website for public-figure profiles.

## Included
- Homepage
- Dr. Janette Nesheiwat profile
- Clearly labeled rumor-check section
- 10 additional doctor/public-figure directory entries
- About, Editorial Policy and Contact pages
- SEO title/description and basic ProfilePage structured data
- Responsive design
- User-provided Janette photo in `assets/janette-nesheiwat.jpg`

## Important editorial note
The Janette marriage section intentionally does NOT state as fact that she is married to Roberto Uy/Urbina. Current web results located no credible independent confirmation of that claim. The site instead labels it as an unverified online claim and points readers to the available reporting.

## Deployment
Upload the contents to GitHub Pages, Netlify or Vercel. Before publishing:
1. Replace `https://example.com/...` in the JSON-LD with the real URL.
2. Replace `editor@yourdomain.com`.
3. Add a real sitemap.xml and robots.txt after the final domain is chosen.
4. Add source links and update dates as new reporting becomes available.
5. Use Google Search Console after deployment to request indexing.
